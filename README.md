## Про дождь наверху

Баннер снят покадрово и идёт 10 секунд. Тёмная и светлая версии подставляются
автоматически по теме GitHub — `<picture>` с `prefers-color-scheme`.

Как это устроено:

- контуры букв взяты **векторами из самого шрифта**, а не набраны текстом — надпись
  одинакова на любой машине, где бы шрифта ни оказалось;
- капли падают вразнобой, каждая **отскакивает** от контура тонкой хаотичной взвесью;
- в точке удара растёт мягкое пятно маски, и силуэт буквы **проявляется плавно**,
  а не выскакивает целиком.

Все варианты лежат рядом и полностью самодостаточны:
